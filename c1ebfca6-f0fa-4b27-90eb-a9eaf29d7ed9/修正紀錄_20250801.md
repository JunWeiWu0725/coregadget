# Angular 點名小幫手系統修正紀錄

## 概述
本文件記錄了對 Angular 點名小幫手系統進行的各項修正與改進。

## 修正項目

### 1. 畫面字體大小調整
**問題**：使用者詢問如何調大 Cursor 畫面字體
**解決方案**：
- 使用快捷鍵：`Cmd` + `+`（Mac）放大畫面
- 調整 Cursor 編輯器設定：修改 `Editor: Font Size`
- 直接修改 `settings.json`：設定 `"editor.fontSize": 20`

### 2. studentIDList 空白資料問題
**問題**：`studentIDList` 陣列會多一個空白的資料
**原因**：`teacherHelpers` 陣列中有 `StudentID` 為空字串或 `undefined` 的物件
**解決方案**：
- 在 push 到 `teacherHelpers` 前加入 `StudentID` 非空判斷
- 在組合 `studentIDList` 時過濾空值
- 修改位置：`src/app/pages/teacher-helper.component.ts`

```typescript
// 修正前
this.teacherHelpers.push(tea);

// 修正後  
if (item.StudentID) {
  this.teacherHelpers.push(tea);
}
```

### 3. courseList 資料結構統一
**問題**：`courseList` 與 `classList` 的資料結構不一致
**解決方案**：
- 將 `courseList` 的處理方式改為與 `classList` 相同
- 同一課程的學生合併到 `Students` 陣列中
- 修改位置：`src/app/pages/setting.component.ts`

```typescript
// 修正後的 courseList 處理
const targetCourses = [];
const tempCourseList = [].concat(rsp.Course || []);
tempCourseList.forEach(course => {
  let targetCourse = targetCourses.find(c => course.CourseID === c.CourseID);
  if (!targetCourse) {
    targetCourse = { ...course };
    targetCourse.Students = [{ StudentID: course.StudentID, StudentName: course.StudentName }];
    targetCourses.push(targetCourse);
  } else {
    targetCourse.Students.push({ StudentID: course.StudentID, StudentName: course.StudentName });
  }
});
```

### 4. courseList 畫面顯示調整
**問題**：資料結構改變後，畫面顯示需要對應調整
**解決方案**：
- 修改 `src/app/pages/setting.component.html`
- 改用 `*ngFor="let stud of course.Students"` 顯示學生列表

```html
<!-- 修正前 -->
<span>{{course.StudentName}}</span>

<!-- 修正後 -->
<div *ngFor="let stud of course.Students">
  <span>{{stud.StudentName}}</span>
</div>
```

### 5. Unicode 罕用字顯示問題
**問題**：學生姓名「黃子𦭳」顯示為「黃子&#x26b73;」
**原因**：使用 `{{}}` 插值表達式無法正確顯示被 HTML 轉義的 Unicode 字元
**解決方案**：
- `teacher-helper.component.html`：使用 `[innerHTML]="student.Name"`
- `setting.component.html`：將 `{{stud.StudentName}}` 改為 `<span [innerHTML]="stud.StudentName"></span>`
- `student-pick.component.html`：保持原有的 `[innerHTML]` 用法

### 6. 小幫手人數限制
**需求**：限制小幫手只能選擇 2 位
**解決方案**：
- 修改 `changeTeacherHelper` 方法
- 加入人數檢查與友善提示
- 修改位置：`src/app/pages/teacher-helper.component.ts`

```typescript
changeTeacherHelper(stu: Student) {
  const targetStud = this.teacherHelpers.find(s => s.StudentID === stu.StudentID);
  
  if (targetStud) {
    // 取消選擇
    this.teacherHelpers = this.teacherHelpers.filter(th => th.StudentID !== stu.StudentID);
  } else {
    // 檢查是否已達到2位小幫手的限制
    if (this.teacherHelpers.length >= 2) {
      this.alert.snack("最多只能選擇2位小幫手");
      return;
    }
    
    if (!targetStud && stu.StudentID) {
      this.teacherHelpers.push({ StudentID: stu.StudentID, StudentName: stu.Name, StudentNumber: stu.StudentNumber });
    }
  }
}
```

## 重要提醒

### Unicode 字元顯示
- 如果學生姓名含有罕用字，建議使用 `[innerHTML]` 而非 `{{}}`
- 確保資料來源的一致性，避免部分資料被 HTML 轉義

### 資料結構一致性
- `classList` 和 `courseList` 現在都使用相同的資料結構
- 每個班級/課程都有 `Students` 陣列包含所有學生資訊

### 人數限制
- 小幫手人數限制為 2 位
- 可透過修改 `>= 2` 的數值來調整限制人數
