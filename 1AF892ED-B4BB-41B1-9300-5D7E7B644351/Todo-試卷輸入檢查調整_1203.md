## 1️⃣ 調整 enterGrade 函式邏輯

### 步驟 1：找到 enterGrade 函式

搜尋：

```js
$scope.enterGrade = function (event) {
```

確認裡面已有以下結構（大意類似）：

```js
$scope.enterGrade = function (event) {
    if (event && (event.keyCode !== 13 || $scope.isMobile)) return;

    if ($scope.current.Value && typeof $scope.current.Value === 'string') {
        $scope.current.Value = window.convertToHalfWidth($scope.current.Value);
    }

    var flag = false;
    if ($scope.current.Exam.Type == 'Number') {
        var temp = Number($scope.current.Value);
        // 數值檢查、Range.Min / Range.Max、缺考設定等原本邏輯...
    } else {
        flag = true;
    }

    if (flag) {
        $scope.submitGrade();
    }
};
```

### 步驟 2：在 `if ($scope.current.Exam.Type == 'Number') {` 內最前面加入「試卷檢查」

在這行之後：

```js
if ($scope.current.Exam.Type == 'Number') {
```

直接加入以下區塊：

```js
    // ✅ 試卷模式：只允許數字 / 空白 / "-"
    if ($scope.current.Exam.SubName === '試卷') {
        var raw = ($scope.current.Value || '').toString().trim();

        // 空白與 "-" 允許：空白 = 不輸入，"-" = 清空
        if (raw !== '' && raw !== '-') {
            // 其餘必須可轉成數字
            if (isNaN(Number(raw))) {
                alert('試卷成績必須為數字（或輸入「-」代表清空），不可輸入缺考代碼。');

                // 中止後續流程，不進行原本的數值處理，也不呼叫 submitGrade
                return;
            }
        }
    }
```

> ⚠ 注意：只在這裡「新增」上述區塊，**後面原本的 temp / Range / examExtensionMap / flag 邏輯一律保留，不要刪除或改寫**。

### 步驟 3：保留原本數值與缺考處理邏輯

在新加的試卷檢查後方，應接上原本既有的邏輯，例如：

```js
    var temp = Number($scope.current.Value);
    if (!isNaN(temp)
        && (!$scope.current.Exam.Range || (!$scope.current.Exam.Range.Max && $scope.current.Exam.Range.Max !== 0) || temp <= $scope.current.Exam.Range.Max)
        && (!$scope.current.Exam.Range || (!$scope.current.Exam.Range.Min && $scope.current.Exam.Range.Min !== 0) || temp >= $scope.current.Exam.Range.Min)) {
        flag = true;

        if (!$scope.current.Exam.Group) {
            var round = Math.pow(10, $scope.params[$scope.current.Exam.Name + 'Round'] || $scope.params.DefaultRound);
            temp = Math.round(temp * round) / round;
        }
    }

    if ($scope.current.Value == "-") {
        flag = true;
    }

    var tempMapText = '';

    if ($scope.current.Exam.ExamID !== '學期成績')
        $scope.examExtensionMap.forEach(function (map) {
            if (map.use_text == $scope.current.Value) {
                tempMapText = map.use_text;
                flag = true;
            }
        });

    if (flag) {
        if ($scope.current.Value != "" && $scope.current.Value != tempMapText && $scope.current.Value != "-") {
            $scope.current.Value = temp;
        } else if ($scope.current.Value === "-") {
            $scope.current.Value = '';
        }
    }
```

`else { flag = true; }` 以及最後 `if (flag) { $scope.submitGrade(); }` 的結構保持不變。

## 2️⃣ 測試驗證（對應 TestCase01.txt）

請依 `TestCase01.txt` 進行至少以下驗證：

### ✅ 一般模式（非試卷）

1. **輸入 80**
   - 顯示與儲存後讀取皆為 80 分
   - Score = 80，UseText 清空

2. **輸入 0**
   - 顯示與儲存後讀取皆為 0 分
   - Score = 0，UseText 清空

3. **輸入缺考設定文字（例如「缺」）**
   - 顯示與儲存後皆為「缺」
   - Score = -1 或 -2（依後端規則）
   - UseText =「缺」

> ※ 一般模式應完全維持原本行為，不因本次調整而改變。

### ✅ 試卷模式（SubName = '試卷'）

4. **輸入 80**
   - 應可正常儲存
   - PScore = 80（其他欄位依原邏輯處理）

5. **輸入 0**
   - 應可正常儲存
   - PScore = 0

6. **輸入「缺」或其他非數字文字**
   - 立即跳出「試卷成績必須為數字（或輸入「-」代表清空），不可輸入缺考代碼。」之提示
   - 停留在同一輸入格，不儲存、不往下一位
   - 使用者需改為數字、`-` 或清空才可繼續
