# Todo-試卷成績輸入修正1202

目標：  
1. 讓「試卷」欄位可以正確輸入並儲存：`0 分`、一般數字成績、與「缺」等缺考文字。  
2. 避免因試卷輸入文字（如「缺」）導致主評量成績變成 NaN 或儲存失敗。  
3. 不影響原本「主評量欄位」既有的 0 分與缺考設定（`examExtensionMap` 邏輯維持不變）。  
4. 完成後請在《高中評量成績輸入調整1202.md》紀錄本次修改。

## Todo 1：修正子成績儲存邏輯，保留 0 與文字（缺考內容）

### 1-1. 位置

檔案：`js/gradebook.js`  
搜尋關鍵字：`B-4: 讀卡子成績 CScore / PScore 寫入` 或 `PScore =`  

找到類似下列區段（實際註解或縮排可能略有差異）：

```js
// B-4: 讀卡子成績 CScore / PScore 寫入
if (examRec.isSubScoreMode && data.Extension) {
    var cScore = studentRec['Exam' + examRec.ExamID + 'CScore'] || '';
    var pScore = studentRec['Exam' + examRec.ExamID + 'PScore'] || '';

    data.Extension.Extension.CScore = cScore;
    data.Extension.Extension.PScore = pScore;
}
```

### 1-2. 問題說明

- 目前使用 `|| ''`：
  - 當試卷輸入 `0` 時，`0 || ''` 會變成 `''`，導致 **0 分被當成空白**，儲存後讀回來變成「沒有成績」。
  - 文字內容（例如「缺」）雖然可以被存成字串，但後續與主評量計算時會容易變 NaN。

### 1-3. 修改目標

- 保留子成績原始輸入內容：
  - 數字：`0`, `80`…
  - 文字：`缺`, `病假`, `曠課`…
- 僅在 `null` 或 `undefined` 時視為空白。

### 1-4. 修改方式

**將上述區段改為以下寫法：**

```js
// B-4: 讀卡子成績 CScore / PScore 寫入
if (examRec.isSubScoreMode && data.Extension) {

    // 僅在 null / undefined 時視為空白；其餘保留原始值（含 0 與文字）
    function normalizeSubScore(raw) {
        if (raw === null || raw === undefined) return '';
        return raw.toString();
    }

    var cScore = normalizeSubScore(studentRec['Exam' + examRec.ExamID + 'CScore']);
    var pScore = normalizeSubScore(studentRec['Exam' + examRec.ExamID + 'PScore']);

    data.Extension.Extension.CScore = cScore;
    data.Extension.Extension.PScore = pScore;
}
```

### 1-5. 預期行為

- 試卷輸入 `0` → 寫入 Extension.PScore = `"0"` → 重新讀取後顯示 `0`。  
- 試卷輸入 `缺` → 寫入 Extension.PScore = `"缺"` → 重新讀取後顯示 `缺`。  
- 試卷輸入 `80` → 寫入 Extension.PScore = `"80"` → 重新讀取後顯示 `80`。  

> 注意：此修改僅影響子成績欄位 CScore/PScore 的儲存方式，**不會影響主評量欄位原本的缺考設定邏輯**。

## Todo 2：修正子成績加總主評量邏輯，避免 NaN

### 2-1. 位置

檔案：`js/gradebook.js`  
搜尋關鍵字：`current.Exam.Group` 或 `template.isSubScoreMode` 或 `PScore`，找到「當前試別是子成績時，將 CScore + PScore 回寫主評量」的程式區段，類似下方：

```js
if ($scope.current.Exam.Group) {
    var examRec = $scope.current.Exam.Group;
    var template = $scope.templateList.find((temp) => temp.ExamID == examRec.ExamID) || {};
    if (template && template.isSubScoreMode) {
        var ps = $scope.current.Student['Exam' + template.ExamID + 'PScore'];
        var cs = $scope.current.Student['Exam' + template.ExamID + 'CScore'];

        // 舊邏輯：直接進行數值加總
        var score = (ps === '' && cs === '') ? '' : add(+ps, +cs);
        $scope.current.Student['Exam' + template.ExamID] = score;
    }
}
```

### 2-2. 問題說明

- 若試卷欄位輸入「缺」等文字：
  - `+ps` 會變成 `NaN`，最終 `score` 變成 `NaN`。
  - 後續 `buildScoreAndExtension()` 會把 NaN 判定為「成績格式錯誤」，導致該評量無法正確儲存。

### 2-3. 修改目標

- 只讓 **可轉為數字的值** 參與加總，文字（例如「缺」）仍顯示在子欄位，但不會破壞主評量成績。  
- 若 CScore / PScore 都沒有合法數字，主評量欄位顯示空白。  
- 保持原本主評量欄位的缺考設定（examExtensionMap）邏輯不變。

### 2-4. 修改方式

將上述區段改為下列寫法：

```js
if ($scope.current.Exam.Group) {
    var examRec = $scope.current.Exam.Group;
    var template = $scope.templateList.find((temp) => temp.ExamID == examRec.ExamID) || {};
    if (template && template.isSubScoreMode) {
        var ps = $scope.current.Student['Exam' + template.ExamID + 'PScore'];
        var cs = $scope.current.Student['Exam' + template.ExamID + 'CScore'];

        // 僅將可轉為數字的內容拿來加總，避免「缺」等文字造成 NaN
        var psNum = (ps !== null && ps !== undefined && ps !== '' && !isNaN(Number(ps))) ? Number(ps) : null;
        var csNum = (cs !== null && cs !== undefined && cs !== '' && !isNaN(Number(cs))) ? Number(cs) : null;

        var score;

        if (psNum === null && csNum === null) {
            // 沒有任何有效數字 → 主評量留空
            score = '';
        } else {
            var total = 0;
            if (psNum !== null) total = add(total, psNum);
            if (csNum !== null) total = add(total, csNum);
            score = total;
        }

        $scope.current.Student['Exam' + template.ExamID] = score;
    }
}
```

### 2-5. 預期行為

- 試卷輸入 `80`、讀卡空白 → 主評量 = 80。  
- 試卷輸入 `0`、讀卡空白 → 主評量 = 0。  
- 試卷輸入 `缺`、讀卡有數字 → 主評量只使用讀卡成績計算。  
- 試卷與讀卡都輸入文字 / 非數字 → 主評量為空白，不會出現 NaN。

## Todo 3：測試情境（手動測試）

請在修改程式後，重新部署 / 更新 Gadget，並在實際環境進行以下測試（建議使用測試課程與測試學生）：

### 3-1. 試卷輸入 0 分

1. 進入「成績管理」模式。  
2. 選擇某課程 → 選擇有「讀卡/試卷」設定的定期評量。  
3. 在某位學生的「xxx 試卷」欄位輸入 `0`，儲存。  
4. 關閉並重新開啟 Gadget / 重新整理頁面。  
5. 驗證：
   - 該學生的「試卷」欄位顯示 `0`。  
   - 相關主評量欄位（例如第一次段考）可正常儲存與顯示（若僅有試卷分數，主評量應為 0）。  

### 3-2. 試卷輸入「缺」

1. 針對同一位學生，在「xxx 試卷」欄位輸入 `缺`，儲存。  
2. 重新整理頁面。  
3. 驗證：
   - 試卷欄位顯示「缺」，不會被清空。  
   - 該定期評量的主評量欄位不會變成 NaN，能正常儲存（無數字時可為空白）。  
   - 不影響主評量欄位原本依 `examExtensionMap` 設定的缺考行為（主評量直接輸入缺考代碼仍維持原有邏輯）。  

### 3-3. 試卷輸入 80 分

1. 在「xxx 試卷」欄位輸入 `80`，儲存。  
2. 重新整理頁面。  
3. 驗證：
   - 試卷欄位顯示 `80`。  
   - 若讀卡欄位空白，主評量欄位應顯示 80。  
   - 儲存與再次讀取皆正常。  

### 3-4. 回歸測試：主評量欄位 0 分與缺考設定

1. 在主評量欄位（非子成績）直接輸入 `0` → 儲存並重新整理。  
   - 預期：0 分可正常儲存與顯示。  
2. 在主評量欄位輸入已在 `examExtensionMap` 定義的缺考代碼（例如「缺」、「免試」等）→ 儲存。  
   - 預期：依既有缺考設定運作（對應的實際分數 / score_type 不變）。
