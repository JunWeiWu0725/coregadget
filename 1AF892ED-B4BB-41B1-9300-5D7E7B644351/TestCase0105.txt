# 測試用例 - 高中評量成績「文字評量」輸入/儲存/讀取調整（0105）

## 測試環境
- 檔案：`gradebook.js`
- 功能：文字評量輸入、儲存、讀取
- 測試日期：2026-01-05

---

## 測試案例 1：一般分數 + 文字評量

### 前置資料
- 學生：測試學生A
- 評量：第一次段考
- 初始狀態：無成績、無文字評量

### 操作步驟
1. 輸入分數：`80`
2. 輸入文字評量：`表現良好，持續加油`
3. 點擊儲存
4. 重新載入頁面
5. 檢查該學生該評量的分數與文字評量

### 預期結果
- 分數顯示：`80`
- 文字評量顯示：`表現良好，持續加油`
- 後端資料：`Extension.Extension.Text = "表現良好，持續加油"`

### 實際結果
- [ ] 待測試

## 測試案例 2：一般分數 + 清空文字評量

### 前置資料
- 學生：測試學生B
- 評量：第一次段考
- 初始狀態：已有文字評量 `先前評語`

### 操作步驟
1. 確認文字評量欄位有值：`先前評語`
2. 輸入分數：`75`
3. 將文字評量欄位刪除為空字串
4. 點擊儲存
5. 重新載入頁面
6. 檢查該學生該評量的文字評量

### 預期結果
- 分數顯示：`75`
- 文字評量顯示：空（後端確實清空）
- 後端資料：`Extension.Extension.Text = ""` 或 Extension 節點保留但 Text 為空

### 實際結果
- [ ] 待測試

## 測試案例 3：缺考/特殊成績 + 文字評量（若業務允許同時存在）

### 前置資料
- 學生：測試學生C
- 評量：第一次段考
- 缺考設定：`examExtensionMap` 中有缺考代碼（例如 `UseText="缺"`, `Text="缺考"`）

### 操作步驟
1. 輸入缺考代碼（例如：`缺`）
2. 輸入文字評量：`請補考`
3. 點擊儲存
4. 重新載入頁面
5. 檢查該學生該評量的缺考資訊與文字評量

### 預期結果
- 分數顯示：缺考代碼（例如：`缺`）
- 缺考資訊：`UseText` 與 `Score` 正確
- 文字評量顯示：`請補考`（若系統設計允許同時存在）
- 後端資料：`Extension.Extension.Text = "請補考"`（文字評量可能覆蓋缺考的 Text）

### 實際結果
- [ ] 待測試
- 備註：需確認系統設計是否允許缺考與文字評量同時存在，或文字評量會覆蓋缺考 Text

## 測試案例 7：從有文字評量改為一般分數（無文字評量）

### 前置資料
- 學生：測試學生G
- 評量：第一次段考
- 初始狀態：分數 `80`，文字評量 `先前評語`

### 操作步驟
1. 確認初始狀態：分數 `80`，文字評量 `先前評語`
2. 修改分數為：`90`
3. 不修改文字評量欄位（保持原值或刪除）
4. 點擊儲存
5. 重新載入頁面
6. 檢查該學生該評量的分數與文字評量

### 預期結果
- 分數顯示：`90`
- 文字評量顯示：若欄位未刪除則保持原值；若刪除則為空
- 後端資料：依實際操作而定

- [ ] 待測試
