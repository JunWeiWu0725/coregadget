# 高中評量成績輸入調整 1202

## 修改日期
2025-12-02

## 調整主題

試卷子成績輸入 0 分與缺考內容之儲存與顯示修正。  
避免文字輸入導致主評量成績 NaN。  
不影響原本「主評量欄位」既有的 0 分與缺考設定（`examExtensionMap` 邏輯維持不變）。

## 改動檔案

- `js/gradebook.js`

## 問題說明

### 現象

1. **試卷欄位輸入 0 分後消失**
   - 老師在「xxx 試卷」欄位輸入 `0`，儲存後重新載入，該欄位變成空白。
   - 原因是使用 `|| ''` 時，`0 || ''` 會變成 `''`，導致 0 分被當成空白。

2. **試卷欄位輸入「缺」等文字導致主評量變成 NaN**
   - 當試卷欄位輸入「缺」等文字時，子成績加總邏輯中 `+ps` 會變成 `NaN`。
   - 最終主評量成績變成 `NaN`，導致該評量無法正確儲存。

### 主要原因

1. **子成績儲存邏輯問題**（B-4 區段）
   - 使用 `studentRec['Exam' + examRec.ExamID + 'PScore'] || ''` 時，`0 || ''` 會變成 `''`。
   - 導致 0 分無法正確儲存。

2. **子成績加總邏輯問題**
   - 直接使用 `add(+ps, +cs)` 進行數值加總。
   - 當 `ps` 或 `cs` 為文字（如「缺」）時，`+ps` 會變成 `NaN`，最終 `score` 變成 `NaN`。

## 修改內容

### 1. 修正子成績儲存邏輯，保留 0 與文字（缺考內容）

**位置：** `js/gradebook.js` 第 1719-1726 行

**修改前：**
```javascript
// B-4: 讀卡子成績 CScore / PScore 寫入
if (examRec.isSubScoreMode && data.Extension) {
    var cScore = studentRec['Exam' + examRec.ExamID + 'CScore'] || '';
    var pScore = studentRec['Exam' + examRec.ExamID + 'PScore'] || '';

    data.Extension.Extension.CScore = cScore;
    data.Extension.Extension.PScore = pScore;
}
```

**修改後：**
```javascript
// B-4: 讀卡子成績 CScore / PScore 寫入
if (examRec.isSubScoreMode && data.Extension) {

    // 僅在 null / undefined 時視為空白；其餘保留原始值（含 0 與文字）
    function normalizeSubScore(raw) {
        if (raw === null || raw === undefined) return '';
        return raw.toString();
    }

    var cScore = normalizeSubScore(studentRec['Exam' + examRec.ExamID + 'CScore']);
    var pScore = normalizeSubScore(studentRec['Exam' + examRec.ExamID + 'PScore']);

    data.Extension.Extension.CScore = cScore;
    data.Extension.Extension.PScore = pScore;
}
```

**說明：**
- 新增 `normalizeSubScore` 函式，僅在 `null` 或 `undefined` 時視為空白。
- 保留原始輸入內容：數字（含 0）、文字（如「缺」）皆可正確儲存。

### 2. 修正子成績加總主評量邏輯，避免 NaN

**位置：** `js/gradebook.js` 第 1525-1536 行

**修改前：**
```javascript
if ($scope.current.Exam.Group) {
    var examRec = $scope.current.Exam.Group;
    // 取得定期評量
    var template = $scope.templateList.find((temp) => temp.ExamID == examRec.ExamID) || {};
    if (template && template.isSubScoreMode) {
        var ps = $scope.current.Student['Exam' + template.ExamID + 'PScore'];
        var cs = $scope.current.Student['Exam' + template.ExamID + 'CScore'];

        // var score = (ps == '' && cs == '') ? '' : ps * 1 + cs * 1;
        var score = (ps === '' && cs === '') ? '' : add(+ps, +cs);
        $scope.current.Student['Exam' + template.ExamID] = score;
    }
}
```

**修改後：**
```javascript
if ($scope.current.Exam.Group) {
    var examRec = $scope.current.Exam.Group;
    // 取得定期評量
    var template = $scope.templateList.find((temp) => temp.ExamID == examRec.ExamID) || {};
    if (template && template.isSubScoreMode) {
        var ps = $scope.current.Student['Exam' + template.ExamID + 'PScore'];
        var cs = $scope.current.Student['Exam' + template.ExamID + 'CScore'];

        // 僅將可轉為數字的內容拿來加總，避免「缺」等文字造成 NaN
        var psNum = (ps !== null && ps !== undefined && ps !== '' && !isNaN(Number(ps))) ? Number(ps) : null;
        var csNum = (cs !== null && cs !== undefined && cs !== '' && !isNaN(Number(cs))) ? Number(cs) : null;

        var score;

        if (psNum === null && csNum === null) {
            // 沒有任何有效數字 → 主評量留空
            score = '';
        } else {
            var total = 0;
            if (psNum !== null) total = add(total, psNum);
            if (csNum !== null) total = add(total, csNum);
            score = total;
        }

        $scope.current.Student['Exam' + template.ExamID] = score;
    }
}
```

**說明：**
- 僅將可轉為數字的值參與加總，文字（例如「缺」）仍顯示在子欄位，但不會破壞主評量成績。
- 若 CScore / PScore 都沒有合法數字，主評量欄位顯示空白。
- 保持原本主評量欄位的缺考設定（examExtensionMap）邏輯不變。

## 影響範圍

- 前端教師端 GradeBook 成績輸入 Gadget。
- 僅影響「有讀卡/試卷設定」之定期評量的子成績欄位。
- 主評量欄位原有缺考設定（examExtensionMap）邏輯不變。

## 預期行為

### 試卷輸入 0 分
- 試卷輸入 `0` → 寫入 Extension.PScore = `"0"` → 重新讀取後顯示 `0`。
- 若僅有試卷分數，主評量應為 0。

### 試卷輸入「缺」
- 試卷輸入 `缺` → 寫入 Extension.PScore = `"缺"` → 重新讀取後顯示 `缺`。
- 該定期評量的主評量欄位不會變成 NaN，能正常儲存（無數字時可為空白）。
- 不影響主評量欄位原本依 `examExtensionMap` 設定的缺考行為。

### 試卷輸入一般分數
- 試卷輸入 `80` → 寫入 Extension.PScore = `"80"` → 重新讀取後顯示 `80`。
- 若讀卡欄位空白，主評量欄位應顯示 80。
- 儲存與再次讀取皆正常。

### 混合情境
- 試卷輸入 `80`、讀卡空白 → 主評量 = 80。
- 試卷輸入 `0`、讀卡空白 → 主評量 = 0。
- 試卷輸入 `缺`、讀卡有數字 → 主評量只使用讀卡成績計算。
- 試卷與讀卡都輸入文字 / 非數字 → 主評量為空白，不會出現 NaN。

### 回歸測試：主評量欄位
- 在主評量欄位（非子成績）直接輸入 `0` → 儲存並重新整理，0 分可正常儲存與顯示。
- 在主評量欄位輸入已在 `examExtensionMap` 定義的缺考代碼（例如「缺」、「免試」等）→ 依既有缺考設定運作（對應的實際分數 / score_type 不變）。
