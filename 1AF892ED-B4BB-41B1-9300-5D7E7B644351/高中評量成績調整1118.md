# 高中評量成績調整 - Extension 寫入邏輯修正

## 修改目的

修正 Extension 寫入邏輯，禁止一般分數（如 `52.5`）寫入 Extension，確保：
- 一般分數僅寫入 `<Score>`，不產生 Extension
- 特殊成績（缺考、免試等）的 Extension 完全來自 `examExtensionMap` 對照表
- 避免出現 `<UseText>52.5</UseText>` 或 `<Text>undefined</Text>` 等錯誤格式

## 改動檔案

- `js/gradebook.js`

## 新增函式

### `buildScoreAndExtension(rawValue, examExtensionMap)`

**位置：** `gradebook.js` 第 136-181 行（與 `rounding`、`add` 等工具函式並列）

**功能：**
- 統一處理原始輸入值，判斷是否為特殊成績
- 若為特殊成績（在 `examExtensionMap` 中找到對應），返回 `extension` 物件
- 若為一般數字，僅返回 `score`，`extension` 為 `null`
- 若格式錯誤，返回 `error` 訊息

**回傳格式：**
```javascript
{
    score: number|null,      // 分數值
    extension: {              // 僅特殊成績時有值
        Score: number,
        UseText: string,
        Text: string
    }|null,
    error: string|null        // 格式錯誤時有值
}
```

## 調整寫入邏輯點位

### `SetCourseExamScoreWithExtension()` 函式

**位置：** `gradebook.js` 第 1607 行開始

**修改內容：**

1. **移除舊邏輯：**
   - 移除直接根據 `score_type` 判斷並手動設定 `score` 和 `use_text` 的程式碼
   - 移除直接將原始值寫入 Extension 的邏輯
   - 移除 `Text` 欄位直接使用 `_文字評量` 欄位的邏輯

2. **改用新邏輯：**
   - 使用 `buildScoreAndExtension()` 統一處理原始輸入值
   - 僅在 `be.extension` 不為 `null` 時才建立 Extension 物件
   - Extension 的 `Score`、`UseText`、`Text` 完全來自 `examExtensionMap`

**修改前：**
```javascript
var score = studentRec['Exam' + examRec.ExamID];
var score_type = studentRec['Exam' + examRec.ExamID + 'score_type'];
var use_text = '';

if (score_type == '0分') {
    score = -1;
    use_text = studentRec['Exam' + examRec.ExamID];
}
if (score_type == '免試') {
    score = -2;
    use_text = studentRec['Exam' + examRec.ExamID];
}

var data = {
    '@StudentID': studentRec.StudentID,
    '@Score': score,
    Extension: {
        Extension: {
            Score: studentRec['Exam' + examRec.ExamID],
            UseText: use_text,
            Text: text.replace(/'/g, "''")
        }
    }
};
```

**修改後：**
```javascript
var rawValue = studentRec['Exam' + examRec.ExamID];

var be = buildScoreAndExtension(rawValue, $scope.examExtensionMap);

if (be.error) {
    return;
}

var data = {
    '@StudentID': studentRec.StudentID,
    '@Score': (be.score == null ? '' : be.score)
};

if (be.extension) {
    data.Extension = {
        Extension: {
            Score: be.extension.Score,
            UseText: be.extension.UseText,
            Text: be.extension.Text
        }
    };
}
```

## 影響範圍

### 寫入端（本次修改）
- ✅ 一般分數（如 `52.5`）不再產生 Extension
- ✅ 特殊成績的 Extension 完全來自 `examExtensionMap`
- ✅ 移除所有直接使用 `rawValue` 產生 `UseText` 或 `Text` 的邏輯

### 讀取端（Cynthia new）
- ✅ 讀取邏輯不受影響，仍能正確判斷特殊成績
- ✅ 相容舊制缺考格式（`ext.use_text=='' && ext.Score =='缺' && Score =='-1'`）

## 後續注意事項

1. **Extension 使用原則：**
   - Extension 僅用於特殊成績（缺考、免試等）
   - 一般分數永遠不產生 Extension
   - Extension 的內容必須完全來自 `examExtensionMap`

2. **新增特殊成績類型：**
   - 需在後端 `examExtensionMap` 中設定對應的 `use_value`、`use_text`、`report_value`
   - 前端無需修改程式碼，`buildScoreAndExtension()` 會自動處理

3. **相容性：**
   - 讀取端仍支援舊制缺考格式
   - 新寫入的資料完全符合新制規範

4. **錯誤處理：**
   - 若輸入值不在 `examExtensionMap` 且非數字，`buildScoreAndExtension()` 會返回 `error`
   - 目前遇到錯誤時會 `return`，不儲存該筆資料
   - 可考慮未來加入錯誤提示機制
