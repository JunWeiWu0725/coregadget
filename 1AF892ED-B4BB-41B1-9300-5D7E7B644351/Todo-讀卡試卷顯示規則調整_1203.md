# Todo-讀卡試卷顯示規則調整_1203.md

## 🎯 目標

在 `content.htm` 的右側表格 **「特殊成績輸入方式及計算規則」**
下方加入提示文字：

> ✬ 已啟用讀卡成績，不採用缺免設定。

**顯示條件：** - examList 內有任一 examItem 的 `SubName == "讀卡"`\
- 或 examItem 的 `SubName == "試卷"`\
→ 顯示提示文字\
- 若兩者皆無 → 不顯示

修改完成後，請將本次調整紀錄於\
**《高中評量成績輸入調整1203.md》**

## 📌 修改檔案：content.htm

### 1️⃣ 尋找定位段落

搜尋以下 HTML（表格標題）：

    <th colspan="3">特殊成績輸入方式及計算規則</th>

往下定位到以下段落：

``` html
<tbody>
    <tr>
        <td>項目</td>
        <td>輸入內容</td>
        <td>分數認定</td>
    </tr>
</tbody>
<tbody>
    <tr ng-repeat="item in examExtensionMap">
        <td>{{ item.report_value }}</td>
        <td>{{ item.use_text }}</td>
        <td>{{ item.score_type }}</td>
    </tr>
</tbody>
```

### 2️⃣ 在上述段落後面新增以下程式碼（請直接貼上）

``` html
<!-- 讀卡 / 試卷 啟用提示 -->
<tbody ng-if="(examList | filter:{SubName:'讀卡'}).length > 0 || (examList | filter:{SubName:'試卷'}).length > 0">
    <tr>
        <td colspan="3" class="text-danger" style="padding:5px;">
            ✬ 已啟用讀卡成績，不採用缺免設定。
        </td>
    </tr>
</tbody>
```
