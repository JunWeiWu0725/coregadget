## 2️⃣ 調整匯入解析邏輯：試卷只能解析數字

### 2-1. 找到匯入流程建立區塊（gradebook.js）

在 `gradebook.js` 搜尋建立匯入流程的程式碼，類似：

```js
var importProcesses = [];
[].concat($scope.examList).forEach(function (examRec, index) {
    if (examRec.Type == 'Number' && examRec.Permission == "Editor") {
        var importProcess = {
            Name: '匯入' + (examRec.Name === '學期成績' ? '課程成績' : examRec.Name),
            Parse: function () {
                // 解析邏輯
            },
            Import: function () {
                // 匯入寫回邏輯
            }
        };

        importProcesses.push(importProcess);
    }
});
```

### 2-2. 修改 Parse 邏輯：試卷不得使用缺考文字

在 `importProcess.Parse` 中，原本會將每一列切成 `ParseValues[i]`，並依下列順序判斷：

1. 轉半形
2. 嘗試轉為數字 `temp = Number(...)`
3. 若是 0~100 的數字 → 合法
4. 若為 `-` → 當作清空
5. 若為缺考設定文案（在 `examExtensionMap` 裡）→ 合法
6. 否則顯示 `'錯誤'` 或 `'超過'`，並標記 `HasError = true`

我們要做的是：「**試卷（SubName='試卷'）不再走第 5 步的缺考文字判斷**」。

請在 Parse 的迴圈內，找到如下程式碼：

```js
if (examRec.Name !== '學期成績')
    $scope.examExtensionMap.forEach(function (map) {
        if (map.use_text == importProcess.ParseValues[i]) {
            flag = true;
        }
    });
```

將它改成：

```js
// 一般模式可以使用缺考設定文字；試卷模式禁止
if (examRec.Name !== '學期成績' && examRec.SubName != '試卷')
    $scope.examExtensionMap.forEach(function (map) {
        if (map.use_text == importProcess.ParseValues[i]) {
            flag = true;
        }
    });
```

> 說明：  
> - **一般模式**（非學期成績且 SubName != '試卷'）：維持原本可匯入缺考文字的邏輯。  
> - **試卷模式**（SubName = '試卷'）：**不再對缺考文字放行**，只有數字 / `-` / 空白可以通過，其他將標記為錯誤。

### 2-3. Import（匯入寫回）邏輯同步排除試卷的 score_type 設定

在 `importProcess.Import` 中，對於每一位學生會有類似邏輯：

```js
if (examRec.Name !== '學期成績')
    $scope.examExtensionMap.forEach(function (map) {
        if (map.use_text == importProcess.ParseValues[index]) {
            stuRec['Exam' + examRec.ExamID + 'score_type'] = map.score_type;
        }
    });
```

請同樣改成：

```js
// 一般模式可設定缺考 score_type；試卷模式不使用缺考設定
if (examRec.Name !== '學期成績' && examRec.SubName != '試卷')
    $scope.examExtensionMap.forEach(function (map) {
        if (map.use_text == importProcess.ParseValues[index]) {
            stuRec['Exam' + examRec.ExamID + 'score_type'] = map.score_type;
        }
    });
```

> 說明：  
> - 一般模式：仍可根據缺考文字設定對應的 `score_type`。  
> - 試卷模式：不再透過匯入寫入缺考 `score_type`，避免違反「試卷不採用缺免設定」規則。
