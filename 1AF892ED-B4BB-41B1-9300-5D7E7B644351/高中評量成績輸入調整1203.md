# 高中評量成績輸入調整1203

## 📝 修改目的

在「特殊成績輸入方式及計算規則」表格下方新增提示文字，當 examList 內有任一 examItem 的 `SubName == "讀卡"` 或 `SubName == "試卷"` 時，顯示提示訊息告知使用者已啟用讀卡成績，不採用缺免設定。

## 📌 修改段落與檔案

**檔案：** `content.htm`

**修改位置：** 右側表格「特殊成績輸入方式及計算規則」下方

**修改段落：** 在第 438-444 行的 `<tbody>` 區塊（顯示 examExtensionMap 項目）之後，新增一個條件式顯示的 `<tbody>` 區塊。

## 🔧 新增 ng-if 顯示規則

新增以下 HTML 程式碼：

```html
<!-- 讀卡 / 試卷 啟用提示 -->
<tbody ng-if="(examList | filter:{SubName:'讀卡'}).length > 0 || (examList | filter:{SubName:'試卷'}).length > 0">
    <tr>
        <td colspan="3" class="text-danger" style="padding:5px;">
            ✬ 已啟用讀卡成績，不採用缺免設定。
        </td>
    </tr>
</tbody>
```

**顯示條件：**
- 當 `examList` 內有任一 `examItem` 的 `SubName == "讀卡"` → 顯示提示文字
- 或 `examItem` 的 `SubName == "試卷"` → 顯示提示文字
- 若兩者皆無 → 不顯示

**技術說明：**
- 使用 AngularJS 的 `filter` 過濾器檢查 examList 中是否存在 SubName 為「讀卡」或「試卷」的項目
- 使用 `ng-if` 指令進行條件式渲染
- 提示文字使用 `text-danger` 類別以紅色顯示，並設定適當的 padding

# 試卷輸入檢查調整_1203

## 📝 修改目的

調整 `gradebook.js` 中「成績輸入」邏輯，讓試卷模式（SubName = '試卷'）只允許輸入數字、空白或「-」，若輸入缺考代碼（如「缺」）或其他非數字文字，則跳出提醒並停留在編輯狀態，不儲存、不往下一位。一般非試卷模式維持原本行為，允許 examExtensionMap 內設定的缺考文字。

## 📌 修改檔案

**檔案：** `gradebook.js`

**修改位置：** `enterGrade` 函式內，`if ($scope.current.Exam.Type == 'Number')` 區塊的最前面

## 🔧 修改內容摘要

在 `enterGrade` 函式中的 `if ($scope.current.Exam.Type == 'Number')` 區塊內最前面，新增試卷模式檢查：

```javascript
// ✅ 試卷模式：只允許數字 / 空白 / "-"
if ($scope.current.Exam.SubName === '試卷') {
    var raw = ($scope.current.Value || '').toString().trim();

    // 空白與 "-" 允許：空白 = 不輸入，"-" = 清空
    if (raw !== '' && raw !== '-') {
        // 其餘必須可轉成數字
        if (isNaN(Number(raw))) {
            alert('試卷成績必須為數字（或輸入「-」代表清空），不可輸入缺考代碼。');

            // 中止後續流程，不進行原本的數值處理，也不呼叫 submitGrade
            return;
        }
    }
}
```

### 修改邏輯說明

1. **試卷模式（SubName = '試卷'）限制：**
   - 只允許：數字（含 0、可含小數、需符合 Range.Min / Range.Max）、空白、`-`（代表清空）
   - 若輸入「缺」或其他非數字文字：
     - 立即跳出「試卷成績必須為數字（或輸入「-」代表清空），不可輸入缺考代碼。」提示
     - 使用 `return` 中止後續流程，停留在編輯狀態，不呼叫 `submitGrade()`，不往下一位

2. **一般非試卷模式：**
   - 維持原本行為不變
   - 允許數字分數
   - 允許 examExtensionMap 內設定的缺考文字（例如「缺」等）
   - 允許 `-` 代表清空

3. **保留原有邏輯：**
   - 所有原本的數值檢查、Range.Min / Range.Max 驗證、examExtensionMap 處理等邏輯都保持不變
   - 只在試卷模式下提前檢查並阻止非數字輸入

# 匯入試卷顯示與解析調整_1203

## 📝 修改目的

1. **調整匯入畫面「特殊成績輸入方式及計算規則」表格說明**
   - 當目前課程有「讀卡」或「試卷」欄位時（試卷模式）：顯示提示文字：`✬ 已啟用讀卡成績，不採用缺免設定。`
   - 當課程為一般模式（沒有讀卡與試卷）：不顯示該提示文字。

2. **調整匯入解析邏輯（Import → Parse）**
   - 試卷模式（SubName =「試卷」）：匯入時「只能解析數字」，非數字一律視為錯誤。
   - 一般模式（非讀卡 + 非試卷）：維持原本邏輯，可解析數字與缺考設定文字。

## 📌 修改檔案與重點

### 1. `content.htm` - 匯入畫面提示文字

**修改位置：** 匯入畫面 (`#importModal`) 的「特殊成績輸入方式及計算規則」表格

**修改內容：** 在 `<tbody>` 中，於 `ng-repeat` 與「空白」列之間插入提示列：

```html
<!-- 讀卡 / 試卷啟用提示（匯入畫面也顯示） -->
<tr ng-if="(examList | filter:{SubName:'讀卡'}).length > 0 || (examList | filter:{SubName:'試卷'}).length > 0">
    <td colspan="3" class="text-danger" style="padding:5px;">
        ✬ 已啟用讀卡成績，不採用缺免設定。
    </td>
</tr>
```

**顯示條件：**
- 當 `examList` 中有 `SubName = '讀卡'` 或 `SubName = '試卷'` 的項目時顯示
- 一般模式（無讀卡與試卷）不顯示

### 2. `gradebook.js` - 匯入 Parse 邏輯

**修改位置：** `importProcess.Parse` 函式內，處理缺考文字判斷的區塊

**修改前：**
```javascript
if (examRec.Name !== '學期成績')
    $scope.examExtensionMap.forEach(function (map) {
        if (map.use_text == importProcess.ParseValues[i]) {
            flag = true;
        }
    });
```

**修改後：**
```javascript
// 一般模式可以使用缺考設定文字；試卷模式禁止
if (examRec.Name !== '學期成績' && examRec.SubName != '試卷')
    $scope.examExtensionMap.forEach(function (map) {
        if (map.use_text == importProcess.ParseValues[i]) {
            flag = true;
        }
    });
```

**說明：**
- 一般模式（非學期成績且 SubName != '試卷'）：維持原本可匯入缺考文字的邏輯
- 試卷模式（SubName = '試卷'）：不再對缺考文字放行，只有數字 / `-` / 空白可以通過，其他將標記為錯誤

### 3. `gradebook.js` - 匯入 Import 邏輯

**修改位置：** `importProcess.Import` 函式內，設定 `score_type` 的區塊

**修改前：**
```javascript
if (examRec.Name !== '學期成績')
    $scope.examExtensionMap.forEach(function (map) {
        if (map.use_text == importProcess.ParseValues[index]) {
            stuRec['Exam' + examRec.ExamID + 'score_type'] = map.score_type;
        }
    });
```

**修改後：**
```javascript
// 一般模式可設定缺考 score_type；試卷模式不使用缺考設定
if (examRec.Name !== '學期成績' && examRec.SubName != '試卷')
    $scope.examExtensionMap.forEach(function (map) {
        if (map.use_text == importProcess.ParseValues[index]) {
            stuRec['Exam' + examRec.ExamID + 'score_type'] = map.score_type;
        }
    });
```

**說明：**
- 一般模式：仍可根據缺考文字設定對應的 `score_type`
- 試卷模式：不再透過匯入寫入缺考 `score_type`，避免違反「試卷不採用缺免設定」規則
