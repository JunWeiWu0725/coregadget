# 學校基本資料管理表單 - 技術規格書

## 1. 專案概述
將原有的 jQuery + Bootstrap 表單改寫為 React + DaisyUI 版本，保持相同的功能但使用現代化的技術架構。

## 2. 技術規格

### 2.1 開發環境
- React 18
- TypeScript
- DaisyUI (light 主題)
- Tailwind CSS
- Vite

### 2.2 專案結構
```
school-info/
├── description.xml         # ischool gadget 設定檔
├── index.html              # 主頁面
├── src/
│   ├── main.tsx           # 應用程式入口點
│   ├── App.tsx            # 根組件（包含表單邏輯）
│   ├── types.ts           # 型別定義
│   ├── validation.ts      # 表單驗證邏輯
│   └── index.css          # 樣式檔案
├── public/                # 靜態資源
│   └── js/
│       └── gadget.js      # ischool gadget
└── README.md              # 專案說明文件
```

### 2.3 功能規格

#### 2.3.1 表單欄位
| 欄位名稱 | 型別 | 驗證規則 | 必填 |
|---------|------|---------|------|
| 學校代碼 | text | - | 是 |
| 學年度 | number | 數字 | 是 |
| 學期 | select | 1 或 2 | 是 |
| 校園首頁網址 | text | URL 格式 | 是 |
| 學校中文名稱 | text | - | 是 |
| 學校英文名稱 | text | - | 是 |
| 學校中文地址 | text | - | 是 |
| 學校英文地址 | text | - | 是 |
| 學校電話 | text | 電話格式 | 是 |
| 學校傳真 | text | 電話格式 | 是 |
| 校長中文姓名 | text | - | 是 |
| 校長英文姓名 | text | - | 是 |
| 教務主任姓名 | text | - | 是 |
| 學務主任姓名 | text | - | 是 |

#### 2.3.2 驗證規則
- 所有必填欄位不得為空
- 學年度必須為數字
- 學期必須為 1 或 2
- 網址必須符合 URL 格式
- 電話和傳真必須符合電話格式

#### 2.3.3 UI 規格
- 使用 DaisyUI 的 light 主題
- 表單布局採用網格式設計
- 錯誤訊息顯示在欄位下方
- 提交按鈕顯示載入狀態
- 響應式設計，支援各種螢幕尺寸

### 2.4 資料流程
1. 表單初始化時載入現有資料
2. 使用者填寫表單
3. 即時驗證輸入資料
4. 提交時進行完整驗證
5. 驗證通過後提交資料
6. 顯示成功/失敗訊息

### 2.5 錯誤處理
- 表單驗證錯誤時顯示中文錯誤訊息
- 系統錯誤時顯示友善的錯誤提示
- 網路錯誤時提供重試選項

### 3. 設計風格
- 極簡主義（Minimalism）：
  - 設計以簡單的線條、寬裕的留白與有限的色彩（主要為白色與淺灰色）為基礎，減少不必要的裝飾。
  - 表單元素（如輸入框、標籤）布局整齊，強調清晰與易用性。
- 現代化數位介面（Modern Digital Interface）：
  - 使用柔和的圓角矩形（rounded rectangles）與淺色背景，符合當前數位產品的設計趨勢。
  - 按鈕（如「取消」與「儲存」）採用簡單的扁平化設計，搭配微妙的陰影或邊框，增加立體感。
- 平滑設計（Smooth Design）：
  - 輸入框與按鈕邊緣平滑，文字對齊一致，營造舒適的視覺體驗。
  - 配色柔和，避免高對比的刺眼感。
- 功能至上（Functionality-First）：
  - 布局以表格形式排列，確保資訊層次分明，優先考慮用戶填寫與閱讀的便利性。
  - 必要字段標示為「*」，突出重要性，設計直觀且實用。
