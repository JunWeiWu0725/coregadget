# 輔導系統開發紀錄

## 學生驗證調試界面 (2024.10.28)

### 功能說明
在匯入一級輔導功能中新增了開發調試界面，用於協助開發者檢查學生驗證邏輯。

### 控制機制
調試界面的顯示受 `content.htm` 中的 `dev_mode` 參數控制：

```javascript
// content.htm 第 30 行
paramValues: { 
  "dev_mode" : true,  // 設為 true 時顯示調試界面
}
```

### 實作位置
- **組件檔案**: `src/app/counsel/import-modal/import-modal.component.ts`
- **模板檔案**: `src/app/counsel/import-modal/import-modal.component.html`
- **樣式檔案**: `src/app/counsel/import-modal/import-modal.component.css`

### 調試界面功能

#### 1. 學生清單顯示
- 顯示所有系統內學生資料
- 即時標記已匹配/未匹配的學生
- 顏色區分：綠色(已匹配) / 灰色(未匹配)
- 顯示匹配統計數量

#### 2. 驗證資料對照
- 顯示當前 Excel 匯入資料
- 每筆資料的匹配結果狀態
- 包含班級、座號、學號、狀態等關鍵欄位

#### 3. 技術資訊
- 當前匯入模式 (班級+座號+狀態 / 學號+狀態)
- 當前使用者角色 (班導師/管理者)
- 驗證代碼位置資訊

### 驗證邏輯位置
**主要驗證位置**: `src/app/counsel-import-validation.service.ts` 第 349-388 行

**學生匹配邏輯**:
```typescript
// 按座號匹配
matchedStudent = this.studentList.find(
  (s) => s.ClassName == row["班級"] && s.SeatNo == row["座號"] && s.Status === compareStatus
);

// 按學號匹配  
matchedStudent = this.studentList.find(
  (s) => s.StudentNumber === row["學號"] && s.Status === compareStatus
);
```

### 使用方式
1. 確保 `content.htm` 中 `dev_mode` 設為 `true`
2. 開啟匯入一級輔導功能
3. 上傳 Excel 檔案後會自動顯示「開發調試：學生清單」按鈕
4. 點擊展開查看詳細的學生匹配狀態

### 正式環境部署
正式環境部署時，將 `content.htm` 中的 `dev_mode` 設為 `false` 即可隱藏調試界面。

### 相關問題修復
同時修復了學生驗證錯誤顯示問題：
- 原因：學生匹配錯誤的 key 與基本欄位驗證衝突
- 解決：使用不同的錯誤 key (`學生匹配(座號)` / `學生匹配(學號)`)
- 確保學生和老師的驗證錯誤都能正確顯示
