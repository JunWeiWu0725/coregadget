# CLAUDE.md

本檔案提供 Claude Code (claude.ai/code) 在此程式碼庫中工作時的指引。

## 專案概述

這是一個為 iSchool 平台建構的**中文教學意見調查小工具**（教學意見調查）。它是一個基於 JavaScript 的網頁應用程式，讓學生能夠完成課程教學意見調查問卷並查看歷史教學意見調查資料。

### 核心元件

- **問卷管理**：學生可以查看、完成和儲存課程教學意見調查表單
- **問卷歷史**：顯示跨學期的歷史完成率和教學意見調查資料
- **課程教學意見調查存取**：學生可根據其完成率查看課程教學意見調查值
- **多語言支援**：主要使用正體中文（zh-TW），並支援 XML 設定

## 架構

### 核心檔案結構

- `js/survey.js` - 主要問卷表單功能和驗證邏輯
- `js/surveyHistory.js` - 歷史問卷資料顯示和教學意見調查率追蹤
- `js/gadget.js` - 大型 jQuery 函式庫（可能是打包/壓縮的第三方程式碼）
- `js/CallbackQueue.js` - 非同步操作管理
- `css/` - 基於 Bootstrap 的樣式和自訂主題
- `description.xml` - 小工具中繼資料和設定

### 技術堆疊

- **前端**：jQuery、Bootstrap 2.x、LESS CSS
- **架構**：使用 iSchool 平台 API 的小工具型網頁應用程式
- **資料格式**：基於 XML 的服務呼叫和回應
- **驗證**：jQuery 驗證外掛程式搭配自訂規則

### 主要功能

1. **問卷表單**：動態題目呈現，支援多種題型（單選、複選、問答）
2. **個案題目**：支援教學意見調查中的個人化個案情境
3. **即時驗證**：字數統計追蹤和必填欄位驗證
4. **預覽模式**：使用者可在最終提交前預覽回答
5. **暫存功能**：草稿回答可儲存並稍後繼續填寫
6. **歷史追蹤**：多學期教學意見調查完成追蹤和比率計算

## 資料流程

應用程式使用服務導向架構，與 `emba.survey.student` 和 `emba.student` 合約通訊：

- 問卷資料擷取（`GetSurvey`、`GetQuestion`、`GetCourseInfo`）
- 回應提交（`SetReply2`）
- 歷史資料（`GetReplyHistory`、`GetAchievingRate`）
- 教學意見調查存取控制（`CanSeeEvaluationRate`）

## 開發注意事項

### 無建置系統

此專案使用直接檔案服務，無建置流程。CSS 使用 LESS 但似乎透過 `less.min.js` 進行客戶端編譯。

### 表單驗證

自訂驗證規則實作包括：
- 字數限制（文字區域最多 500 字元）
- 必填欄位驗證與視覺指示器
- 錯誤反白和焦點管理

### 狀態管理

使用回呼佇列（`CallbackQueue`）管理非同步操作，以及簡單的發布-訂閱模式（`SurveyChanged_Handler`）進行跨元件通訊。

### 國際化

應用程式專為正體中文使用者設計，整個程式碼庫中都有硬編碼的中文文字。錯誤訊息和使用者介面文字皆為中文。
